Publisere endringer

Hva som faktisk skjer når Claude trykker "publiser" — og hva du gjør hvis det går galt.

Det som skjer (under panseret)

1

Claude lagrer filen

Endringen skrives lokalt og deretter til GitHub via en "git commit + push".

2

GitHub mottar endringen

Filen oppdateres på din konto. Du kan se historikken under "Commits".

3

Cloudflare Pages varsles automatisk

En "webhook" forteller Cloudflare at det er ny kode.

4

Cloudflare bygger nettsiden

Astro kjører npm run build som lager HTML-filer fra kildekoden. ~30–60 sek.

5

Live for hele verden

Cloudflares CDN kopierer filene til 300+ datasentre. Besøkende får siden raskt uansett hvor de er.

Total tid: 30 sekunder til ~2 minutter, avhengig av hvor stor endringen er.

Hvor du kan se status

Cloudflare Pages dashboard

Gå til dash.cloudflare.com → Pages → din prosjekt-navn. Du ser:

  • Liste over alle publiseringer (de kalles "deployments")
  • Status: "Building", "Success", eller "Failed"
  • Hvor lang tid byggene tar
  • Hvilket commit som ble bygget

GitHub commits

Gå til github.com/[ditt-brukernavn]/[ditt-repo]/commits for å se hver eneste endring som er gjort. Hver commit har en melding (Claude skriver disse), tidspunkt, og hvilke filer som endret seg.

Hvis bygget feiler

Cloudflare gir deg en feilmelding. De vanligste:

"Build failed: cannot find module 'x'"

Noen pakke mangler. Be Claude kjøre npm install og prøve igjen.

"Build failed: syntax error in [fil]"

Claude skrev noe som ikke er gyldig kode. Be Claude se på filen og rette.

Bra nytt: hvis bygget feiler, går nettsiden IKKE ned. Den siste vellykkede versjonen forblir live til neste vellykket build. Du kan prøve igjen så mange ganger du vil.

Rollback (gå tilbake til forrige versjon)

To måter:

Metode 1: Be Claude angre

"Reverter den siste endringen" — Claude lager en ny commit som angrer forrige.

Metode 2: Cloudflare instant rollback

I Cloudflare dashboard, finn den forrige vellykket build, klikk "Rollback to this deployment". Live på 5 sekunder. Bra hvis du vil sjekke om noe gikk galt før commit-historikken.

Hvor lang tid tar endringer å vises i nettleseren?

Tre lag av tid:

  1. Build-tid (Cloudflare): 30 sek til 2 min
  2. CDN-cache-oppdatering: 5–30 sek
  3. Din browser-cache: kan vise gammel versjon i opptil 1 time hvis du ikke gjør hard reload

Trick for å se nye endringer NÅ:

  • Hard reload: Ctrl + Shift + R (Windows) eller Cmd + Shift + R (Mac)
  • Eller åpne i privat-modus / inkognito
  • Eller legg til en query: dmarketing.no/?nocache=1

Når sider IKKE skal publiseres automatisk

Hvis du vil eksperimentere uten å publisere, kan du si til Claude:

  • Lag en ny side, men ikke publiser ennå. Vis meg en "preview"-URL først.
  • Cloudflare lager automatisk preview-URLer for branches som ikke er main
