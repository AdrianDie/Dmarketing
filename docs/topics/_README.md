# Topics — emner og strategier

Generelle notater som ikke hører hjemme under en spesifikk klient eller beslutning. Her samler du:

- Bransje-innsikt (f.eks. "elektrikere som målgruppe")
- Strategier (pricing, posisjonering, tilbuds-mal)
- Mal-spesifikasjoner (`elektriker-mal`, `bilverksted-mal`)
- Salg/markedsførings-konsepter du jobber med

## Konvensjoner

**Filnavn:** `<kort-emne-navn>.md`. Eksempler:
- `pricing-strategi.md`
- `elektriker-mal.md`
- `tilbuds-mal-tekst.md`
- `landingsside-konvertering.md`

## Når lage en topic-note

- Når en idé er for stor for chatten men ikke en konkret beslutning
- Når flere klienter vil dra nytte av samme innsikt
- Når du vil ha noe Claude kan referere når den lager tilbud eller forslag

## Slik lager du en

Be Claude:

> *"Lag en topic-note `docs/topics/<emne>.md` som oppsummerer hva vi diskuterte i chatten om X."*

## Lenker som gir verdi

- Topic → relaterte klienter (`[[clients/...]]`)
- Topic → mal i `maler/` (selv om disse ikke er Obsidian-noter, kan du linkje med relativ path: `[mal](../../maler/elektriker.html)`)
- Topic → beslutninger (`[[decisions/...]]`)
